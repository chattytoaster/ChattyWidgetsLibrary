# 🧩 Руководство по публикации виджета в ChattyWidgetsLibrary

Добро пожаловать! Этот репозиторий — официальный каталог сообщества для приложения **[ChattyWidgets](https://github.com/chattytoaster/ChattyWidgets)**. Здесь каждый может опубликовать свой виджет, чтобы пользователи могли установить его в один клик прямо из Магазина в приложении.

---

## 🚀 Как отправить свой виджет (Пошагово)

### Шаг 1. Форкните репозиторий
Нажмите кнопку **Fork** в правом верхнем углу этой страницы, чтобы создать копию репозитория в своём GitHub-аккаунте.

---

### Шаг 2. Создайте папку виджета
Склонируйте свой форк и создайте новую папку внутри каталога `widgets/`:
```text
widgets/
└── com.ваш-ник.название-виджета/
    ├── manifest.json   (Обязательно: манифест виджета)
    ├── index.html      (Обязательно: главный файл веб-виджета или Widget.xaml)
    ├── icon.png        (Обязательно: квадратная иконка 128x128 или 256x256)
    └── style.css       (И любые другие скрипты, картинки или стили)
```

> [!IMPORTANT]
> Название папки **обязано** в точности совпадать с полем `"id"` внутри `manifest.json`!
> Рекомендуемый формат ID: `com.ваш_ник.имя_виджета` (только латиница в нижнем регистре, дефисы и точки).

---

### Шаг 3. Заполните `manifest.json`
Пример манифеста для веб-виджета:
```json
{
  "id": "com.ivan.crypto-live",
  "name": "Живые Котировки",
  "version": "1.0.0",
  "author": "Иван Программист",
  "description": "Удобный виджет с курсами криптовалют и уведомлениями об изменении цен.",
  "category": "Финансы",
  "type": "web",
  "entry": "index.html",
  "icon": "icon.png",
  "defaultWidth": 320,
  "defaultHeight": 240,
  "minWidth": 240,
  "minHeight": 180,
  "resizable": true,
  "defaultLayer": "desktop",
  "clickThrough": false,
  "permissions": ["network"]
}
```

> [!TIP]
> **Единый стандарт пропорций 4:3**: чтобы виджеты стояли красиво и гармонично в один ряд на рабочем столе пользователей, всегда используйте базовые размеры **`defaultWidth: 320`** и **`defaultHeight: 240`** с минимальными **`minWidth: 240`** и **`minHeight: 180`**. Подробнее об адаптивной верстке читайте в [DEVELOPMENT.md](DEVELOPMENT.md).

---

### Шаг 4. Проверьте виджет локально
Перед отправкой убедитесь, что виджет корректно запускается и проходит проверку:
```bash
python scripts/validate_widgets.py
```
Скрипт проверит правильность манифеста, наличие обязательных полей, размер и безопасность.

---

### Шаг 5. Отправьте Pull Request
1. Закоммитьте изменения в свой форк:
   ```bash
   git add widgets/com.ваш-ник.название-виджета/
   git commit -m "feat: add com.ваш-ник.название-виджета"
   git push origin main
   ```
2. Откройте страницу репозитория и нажмите зелёную кнопку **"Contribute" → "Open Pull Request"**.
3. Заполните чек-лист в описании PR.
4. Автоматический робот GitHub Actions проверит структуру вашего виджета.
5. Модератор проверит код и нажмёт **Merge**.
6. После слияния робот автоматически упакует виджет в `.chw` и обновит `catalog.json`. Виджет сразу появится в Магазине у всех пользователей!

---

## 🔒 Требования безопасности
- Запрещено добавление скомпилированных исполняемых файлов (`.exe`, `.bat`, `.cmd`, `.dll`).
- Общий размер виджета не должен превышать 25 МБ.
- Виджет не должен содержать вредоносный код, скрытый майнинг или сбор персональных данных.
