Каждый виджет в этом каталоге доступен для быстрой установки в один клик прямо из Магазина приложения.

## 🛠 Как опубликовать свой виджет

Любой желающий может добавить свой виджет в этот каталог!
Подробная пошаговая инструкция описана в **[CONTRIBUTING.md](CONTRIBUTING.md)**.

### Кратко:
1. Сделайте **Fork** репозитория.
2. Добавьте свой виджет в папку `widgets/<id>/`.
3. Отправьте **Pull Request**.
4. После модерации и слияния в `main` GitHub Action автоматически упакует виджет в `.chw` и обновит `catalog.json`.
